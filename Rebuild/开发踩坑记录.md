# PrinterInstaller 开发踩坑记录

> 本文档记录开发过程中遇到的实际问题与解决思路，供后续维护参考。
> 涉及：Tauri 前端、printer-core、macOS/Windows 打印、打包、git。

---

## 1. 前端 / Tauri

### 1.1 CSS 优先级覆盖 `[hidden]`（严重）
- **现象**：`#result { display: flex }` 覆盖了浏览器默认 `[hidden] { display: none }`，导致 result 屏始终显示，与 confirm 屏叠加，窗口被撑高（390 → 428）。
- **修复**：显式加 `.screen[hidden] { display: none !important; }`（`style.css`）。
- **教训**：给元素设 `display` 时，必须显式处理其 hidden 状态的隐藏规则。

### 1.2 `esc()` 对数字参数报错
- **现象**：`esc(4)` 调 `4.replace` 报 TypeError，导致卡在 loading 屏（窗口 80px 高，不进入 confirm）。
- **修复**：`esc()` 先 `String(s)` 再 `.replace`。
- **教训**：i18n 的 `%d` 替换可能传数字，工具函数必须容错。

### 1.3 bash 中全角字符紧邻 `$变量` 导致 unbound variable
- **现象**：`echo "（$CUPSSVC）"`（全角括号）报 `CUPSSVC: unbound variable`。
- **根因**：bash 变量名解析遇到 UTF-8 多字节字符（全角括号）不按 ASCII 截断，把 `CUPSSVC）` 整个当变量名。
- **修复**：改为 `${CUPSSVC}` 明确边界。
- **教训**：shell 脚本中变量后紧跟中文/全角字符必须用 `${var}`。

### 1.4 vite 跨目录 import 被拦
- **现象**：`import ../../../shared-ui/...` 报 `Failed to resolve import`。
- **修复**：vite.config.js 加 `server.fs.allow`；或把共享代码移入项目内（最终采用移入）。
- **教训**：shared-ui 放项目内部即可避免 vite fs 限制。

### 1.5 dev 进程反复退出
- **现象**：`npm run tauri dev` 启动的 app 进程时好时坏，窗口消失。
- **原因**：Rust 改动触发重建 + 竞态；诊断时发现多为 HMR/进程残留。
- **建议**：改动 Rust 后耐心等待重建，必要时 `pkill -f printer-installer-app` 清理残留。

## 2. 窗口 / 布局

### 2.1 窗口高度被"拉长"
- **现象**：给 `#result` 设 `min-height: 346px`，窗口整体变高。
- **修复**：改为按内容收缩 + flex 居中（`#result-body { flex:1; justify-content:center }`）。
- **教训**：窗口高度应由内容决定，不应用固定高度硬撑。

### 2.2 静默启动（visible:false）
- **需求**：启动瞬间不显示白屏/loading。
- **实现**：tauri.conf.json 窗口 `visible:false` + capabilities 加 `core:window:allow-show` + 前端 confirm 渲染后 `getCurrentWindow().show()`。

### 2.3 标题与红绿灯垂直对齐
- **现象**：标题偏高。
- **修复**：`#titlebar { padding: 3px 0 0 78px }`，标题中心与按钮中心对齐（实测 53.75px）。

## 3. macOS 打印

### 3.1 过滤器（filter）缺失导致打印失败（严重）
- **现象**：`Unable to start filter "/Library/Printers/FUJIFILM/Filter/FFACMMCFilter" - No such file or directory`。
- **根因**：reset 脚本删了 `/Library/Printers/FUJIFILM/`，但打印机 PPD 仍引用该过滤器。
- **修复**：把 PPD 引用的过滤器 + PDE 插件内嵌进 printer-core，安装时自动解包到系统目录。
- **验证**：release 二进制含 Mach-O 头（内嵌驱动），单元测试通过。

### 3.2 过滤器权限不被 CUPS 接受（严重）
- **现象**：`FFACMMCFilter 有不安全权限（0100555/uid=501/gid=0）` → `Invalid argument`。
- **根因**：CUPS 以 `_lp` 用户运行，要求过滤器 **root:wheel** 且非其他用户可写；`ditto` 复制保留了源文件 uid=501。
- **修复**：安装脚本加 `chown -R root:wheel /Library/Printers/FUJIFILM` + `chmod -R go-w` + `chmod 555` 过滤器。
- **手动修复命令**：`sudo chown -R root:wheel /Library/Printers/FUJIFILM && chmod 555 .../Filter/FFACMMCFilter`

### 3.3 CUPS 缓存目录被删导致作业卡住
- **现象**：`Unable to create /private/var/spool/cups/cache/job.cache.N`，作业排队不处理。
- **根因**：reset 脚本清 `/var/spool/cups/*` 时把 `cache/` 子目录也删了，cupsd 无法重建。
- **修复**：`mkdir -p /var/spool/cups/cache && chown _lp:_lp`，重启 cupsd。
- **教训**：清 spool 时**不要**删 `cache/` 子目录（保留结构，只清作业文件）。

### 3.4 打印机被自动禁用（disabled）
- **现象**：`Printer-Osaka 已停用 - Filter failed`，作业不执行。
- **根因**：过滤器失败导致 cupsd 自动禁用打印机。
- **修复**：`cupsenable Printer-Osaka`。
- **教训**：修复底层问题后，记得重新启用打印机。

### 3.5 全角括号 + bash 变量（见 1.3）
- 同类问题也出现在 reset 脚本里，用 `${var}` 解决。

### 3.6 架构注意
- 内嵌的 FF 过滤器是 **x86_64** 二进制；Apple Silicon（arm64）机器需 **Rosetta 2** 才能执行。Intel 机器原生可用。

## 4. Windows 打印

### 4.1 驱动安装
- 内嵌 INF 驱动包（`pnputil /add-driver`），退出码 5 = 已存在（视为成功）。
- 型号匹配：`driver.rs` 解析 INF + 相似度打分。

### 4.2 端口/打印机清理
- `reset-ff.ps1`：删除 FF 打印机队列、幽灵打印机（注册表）、IP 端口、驱动包，重启 Spooler。

---

## 5. 打包 / 构建

### 5.1 bundle targets 被覆盖
- **现象**：win 提交把 `bundle.targets` 改成 `["nsis","msi"]`，破坏 mac 打包。
- **修复**：改为 `["app","dmg","nsis","msi"]`（双平台）。
- **教训**：多平台共用 tauri.conf.json 时，targets 必须包含所有需要的平台产物。

### 5.2 osascript 提权在自动化环境报 (1)
- **现象**：`do shell script ... with administrator privileges` 报 `发生"1"类型错误`。
- **根因**：测试环境无法交互输入密码，授权框被取消/超时；非脚本 bug。
- **教训**：需要 root 的操作，脚本用 `sudo`（错误可见）而非 osascript（错误模糊）。

### 5.3 icon 文件
- mac 需 `icon.icns`，win 需 `icon.ico`，双平台都要保留。

## 6. git / 协作

### 6.1 node_modules 误提交
- **现象**：`git add Rebuild/examples/` 把 node_modules 加进去了。
- **修复**：.gitignore 补 `Rebuild/examples/**/node_modules/`、`dist/`、`gen/`；`git rm -r --cached` 取消。
- **教训**：提交前 `git status` 确认，大目录务必检查 ignore。

### 6.2 shared-ui 双份
- **现象**：`Rebuild/shared-ui/`（镜像）与 `examples/.../src/shared-ui/`（真源）重复。
- **修复**：真源放 examples 内，镜像目录 gitignore + sync 脚本维护。
- **教训**：单一真源原则，镜像不进 git。

## 7. 常用命令速查

```bash
# 开发
cd Rebuild/app && npm run tauri dev
# 正式打包
npm run tauri build

# 打印环境重置（macOS）
sudo bash Rebuild/scripts/reset-printers-mac.sh
# 双击运行：Rebuild/PrinterReset.command

# Windows FF 打印环境重置
powershell -ExecutionPolicy Bypass -File .\reset-ff.ps1

# 恢复 FF 驱动（macOS，若被删）
sudo ditto "/Users/v_shinzhang/Desktop/MyInstaller/Payload/FUJIFILM" /Library/Printers/FUJIFILM
# 修复过滤器权限
sudo chown -R root:wheel /Library/Printers/FUJIFILM
sudo chmod 555 /Library/Printers/FUJIFILM/Filter/FFACMMCFilter
# 重新启用打印机
sudo cupsenable Printer-Osaka
# 重启打印服务
sudo launchctl kickstart -k system/org.cups.cupsd

# 打印测试
lp -d Printer-Osaka /etc/hosts
```

## 8. 架构决策记录

| 决策 | 说明 |
|---|---|
| macOS 驱动内嵌 | 过滤器+PDE 内嵌进 printer-core（同 Windows INF 方案），新机器免装驱动即可打印 |
| 双平台共用 printer-core | 前端/i18n/config/flow 复用，仅安装引擎按平台分叉 |
| 静默启动 | 窗口 `visible:false`，confirm 渲染后 `show()` |
| shared-ui 放 onboarding 内 | 避免跨目录引用，`simple` 模式开关控制删除/覆盖功能 |
| onboarding 接入方式 | 加 path 依赖 + 3 个转发 command + 一段 HTML + 几行 JS |
