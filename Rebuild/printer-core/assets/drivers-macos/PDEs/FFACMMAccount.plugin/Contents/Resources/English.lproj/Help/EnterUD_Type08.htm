[Enter User Details] dialog box

This window appears during printing when [Prompt User for Entry when Submitting Job] is selected in the [User Details Setup] dialog box.
You can control the authentication information user can enter in [User Prompt].

Specify Job Owner Name

Select [Specify Job Owner Name] to enter the user details for authentication. This function controls access to print service and keeps track of the usage of printing services by users or user groups.
When [Specify Job Owner Name] option is selected, the following items are displayed: [User ID], [Passcode] and [Account ID].

Note
  • This option is available when [User ID and Account ID] or [All] is selected for [User Prompt].

User ID

Enter the User ID. The User ID entered cannot exceed 32 characters.
User ID is used to control access to print service and keeps track of the usage of printing services by users or user groups.
The entered User ID is registered for the printer icon of each user.

Important
  • If the User ID or Passcode is entered wrongly, the print job will not be processed.
  • Please consult your Administrator regarding User ID and Passcode.
Note
  • If you encounter any problem switching from [Enter Owner Name] to [Use Login Name], click the [Defaults] button.

Passcode

Enter a valid passcode for the User ID. The passcode should be between 4 and 12 characters long. The passcode entered will be displayed as bullet.
If the [Passcode] text box is left empty, no passcode will be used with the specified User ID.

Important
  • If the User ID or Passcode is entered wrongly, the print job will not be processed.
  • Please consult your Administrator regarding User ID and Passcode.

Account ID

Enter the Account ID for Authentication and Accounting function.
The Account ID entered cannot exceed 32 characters.

Important
  • If the User ID or Passcode is entered wrongly, the print job will not be processed.
  • Please consult your Administrator regarding User ID and Passcode.
Note
  • Please make sure to enter User ID or Billing ID.

Specify Billing ID

Select [Specify Billing ID] to enter a Billing ID and Passcode for Charge Print. The print job sent will be temporarily stored on the printer under this ID.
For details on Charge Print and how to release print job at the printer, please refer to the printer manual.

Note
  • Please make sure to enter User ID or Billing ID.
  • This option is available when [Billing ID Only] or [All] is selected for [User Prompt].

Billing ID

Enter a billing ID for Charge Print. The print job sent will be temporarily stored on the printer under this ID.
For details on Charge Print and how to release print job at the printer, please refer to the printer manual.
The Billing ID entered should not exceed 24 characters.

Passcode

Enter a passcode, not exceeding 12 numbers, for the Billing ID. The passcode entered will be displayed as bullet.
If the [Passcode] text box is left empty, no passcode will be set for the Billing ID specified.
