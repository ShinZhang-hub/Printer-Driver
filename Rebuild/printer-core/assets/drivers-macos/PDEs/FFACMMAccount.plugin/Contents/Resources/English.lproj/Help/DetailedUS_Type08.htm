[User Details Setup] dialog box

You can set up user details to be used by default whenever a print job is sent or prompt users to enter their details every time they send a print job.
You can manage the use of network printing in [User Prompt].

Note
  • The settings in this dialog box will be grayed out if you do not have any access rights as Administrator.

Always Use Default User Details

Select this option and set up the information (e.g. Domain Name, User ID, Passcode, Account ID, etc.) to be used by default for authentication when you send a print job.

Domain Name

Specify Domain Name. The Domain Name entered cannot exceed 64 characters.

Specify Job Owner Name

Select how User ID is specified.
The User ID is used to control access to the print service and to audit the print usage of the user or user group registered under this name.

Use Login Name

The OS login name will be used as the User ID.
The login name is displayed in [User ID], and [User ID] text box cannot be edited.
If the login name exceeds 32 characters, only the first 32 characters will be displayed.

Enter Owner Name

Select this option to enter the User ID manually. The User ID entered cannot exceed 32 characters.

Important
  • If the User ID or Passcode is entered wrongly, the print job will not be processed.
  • Please consult your Administrator regarding User ID and Passcode.
Note
  • If you encounter any problem switching from [Enter Owner Name] to [Use Login Name], click the [Defaults] button.
  • A term other than [User ID] may be used on the printer.
  • If Account ID is set up on the printer and Authentication and Accounting function is activated, enter the Account ID too.

User ID

Enter the User ID. The User ID entered cannot exceed 32 characters.
The User ID is used to control access to the print service and to audit the print usage of the user or user group.
The entered User ID is registered for the printer icon of each user.

Important
  • If the User ID or Passcode is entered wrongly, the print job will not be processed.
  • Please consult your Administrator regarding User ID and Passcode.
Note
  • If you encounter any problem switching from [Enter Owner Name] to [Use Login Name], click the [Defaults] button.

Passcode

Enter a valid passcode for the User ID. The passcode should be between 1 and 128 characters long. The passcode entered will be displayed as bullet.

Important
  • If the User ID or Passcode is entered wrongly, the print job will not be processed.
  • Please consult your Administrator regarding User ID and Passcode.

Account ID

If Account ID is set up on the printer and Authentication and Accounting function is activated, enter the Account ID. The Account ID entered cannot exceed 32 characters.

Billing ID

Enter a billing ID for Charge Print so that general users cannot change the charge setting. The print job sent will be temporarily stored on the printer under this ID.
The Billing ID entered should not exceed 24 characters.
For details on Charge Print and how to release print job at the printer, please refer to the printer manual.

Note
  • This option is available when [Billin ID Only] or [All] is selected for [User Prompt].

Passcode

Enter a passcode, not exceeding 12 numbers, for the Billing ID. The passcode entered will be displayed as bullet.
If the [Passcode] text box is left empty, no passcode will be set for the Billing ID specified.

Note
  • This option is available when [Billin ID Only] or [All] is selected for [User Prompt].

Prompt User for Entry when Submitting Job

When [Prompt User for Entry when Submitting Job] is selected, the [Enter User Details] dialog box will appear at the start of printing for users to enter authentication or billing information. Users must enter either their User ID or Billing ID in the [Enter User Details] dialog box to start printing.

Display Last Entered User Details

When the [Display Last Entered User Details] checkbox is selected, the user settings specified previously in the [Enter User Details] dialog box will appear the next time the dialog box is displayed.

Important
  • For Mac OS X 10.7 or later, it will be displayed only when you save the authentication information to the [Preset].

Mask User ID and Domain Name

Select [Mask User ID and Domain Name] to mask the User ID, Billing ID and Domain Name entered in the [Enter User Details] dialog box. The User ID, Billing ID and Domain Name will then be displayed as asterisks.

Mask Account ID

Select [Mask Account ID] to mask the Account ID entered in the [Enter User Details] dialog box. The Account ID will then be displayed as asterisks.
