Job Type

Select one of the following job types: [Normal Print], [Secure Print], [Sample Set], and [Delayed Print].

Note
  • [Please refer to the printer manual on how to output the document at the printer.

[Secure Print]

[Secure Print] stores print data temporarily on the printer to be printed at a convenient time when the user is by the printer. You can specify this feature to print confidential documents. A user ID is required in the [User ID] field to process a Secure Print job.
Click the [Setup...] button to configure the following settings for [Secure Print]:

  • User ID
  • Secure Print Passcode
  • Job Name
  • New Job Name

Please refer to the printer manual on how to output the document at the printer.

Note
  • Please make sure to enter the passcode.

[Sample Set]

If you are printing multiple copies in one print job, [Sample Set] allows you to print only the first copy for checking before proceeding with the remaining copies. A user ID is required in the [User ID] field to process the Sample Set job.
Click the [Setup...] button to configure the following settings for [Sample Set]:

  • User ID
  • Job Name
  • New Job Name

Note
  • This feature will not be available if you are printing one copy or if you have not set the job to be collated.

[Delayed Print]

Delayed Print enables you to store print data temporarily in the printer to be output at a specified time.
Click the [Setup...] button to configure the following settings for [Delayed Print]:

  • Time to Print
  • Job Name
  • New Job Name



[Secure Print] / [Sample Set] / [Delayed Print] dialog box settings

User ID

Enter a user ID for Secure Print and Sample Set jobs.
The user ID should not exceed 24 characters.

<Top>

Secure Print Passcode

Enter the passcode for the [User ID] for Secure Print.
The passcode should not exceed 12 numbers. The numbers entered will be displayed as bullet.

Note
  • Please make sure to enter the passcode.

<Top>

Job Name

[Secure Print] / [Sample Set] / [Delayed Print]

Select the method to specify the job name for Secure Print, Sample Set, and Delayed Print.
If you have selected [Use Existing Name], the job name set in the application will be used as the job name. If this job name is longer than 64 characters, only the first 64 characters will be displayed. No user input is allowed.
If you have selected [Enter Job Name], enter a name for the document in the [New Job Name].

<Top>

New Job Name

[Secure Print] / [Sample Set] / [Delayed Print]

This item is used when [Enter Job Name] is selected in [Job Name].
Enter a job name not exceeding 64 characters.

<Top>

Time to Print

When Delayed Print is selected, enter the time for printing to begin.
You can specify any time from 12:00(AM) to 11:59(PM).
