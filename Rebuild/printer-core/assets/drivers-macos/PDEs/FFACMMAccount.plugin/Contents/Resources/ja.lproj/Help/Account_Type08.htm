認証情報の設定

認証管理モード

認証に関係する各種の設定について、各一般ユーザーが変更できるようにするか、管理者が決めた設定をそのまま使用させるかを選択します。［管理者］または［ユーザー］から選択します。
［管理者］を選択すると、集計管理は管理者が設定したモードで動作し、ユーザーは変更できなくなります。プリンターアイコンごとに、異なる設定ができます。
［ユーザー］を選択すると、各ユーザーが、集計管理の設定を変更できるようになります。ユーザーごとに、異なる設定ができます。
［認証情報の設定...］ボタンをクリックすると、［認証情報の設定］ダイアログボックスが表示されます。プリント出力するときのユーザー認証のための各種設定を行います。

補足
  • 現在ログオンしているユーザーに、プリンタードライバーの設定へのアクセス権がない場合、この項目は淡色表示され、設定を変更できません。

［認証情報の設定...］ボタン

クリックすると、［認証情報の設定］ダイアログボックスが表示されます。プリント出力するときのユーザー認証のための各種設定を行います。

使用する認証情報

印刷時に、ユーザーが入力できる認証情報について設定します。
［User ID / Account ID］を選択すると、認証用IDを使用できます。
［蓄積用ユーザーID］を選択すると、蓄積用IDを使用できます。
［すべて］を選択すると、認証用ID（User IDとAccount ID）と蓄積用ID（蓄積用ユーザーID）を使用できます。

補足
  • 現在ログオンしているユーザーに、プリンタードライバーの設定へのアクセス権がない場合、この項目は淡色表示され、設定を変更できません。
