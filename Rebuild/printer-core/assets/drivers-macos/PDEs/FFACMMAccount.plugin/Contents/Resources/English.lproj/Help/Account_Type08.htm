Job Accounting

Account Mode

This setting is available for users who have access rights to the printer settings. This group of users is known here as the [Administrator]. The Administrators can configure the print driver to allow general users to modify authentication settings in the [User Details Setup] dialog box or restrict general users to use only the authentication settings set up by them. Different levels of permission can be set up for different printer icons in the Printer List.

If [Administrator] is selected, only users with access rights to the printer settings can change the authentication settings in the [User Details Setup] dialog box. The settings in the [User Details Setup] dialog box will be grayed out to general users.
If [User] is selected, general users will be given the permission to change the authentication settings in the [User Details Setup] dialog box.

Note
  • If the current user does not have access rights to the printer settings, [Account Mode] and its setting will be grayed out and not available for changes.

[User Details Setup...] button

Clicking this button displays the [User Details Setup] dialog box where you can specify the settings for user authentication for printing.

User Prompt

Specify which ID to be entered. If [All] is selected, [User ID], [Account ID], and [Billing ID] will be available for selection on the [User Details Setup] dialog box and the [Enter User Details] dialog box. If [User ID and Account ID] is selected, only [User ID], [Account ID], and [Passcode] will be available. If [Billing ID Only] is selected, only [Billing ID] and [Passcode] will be available.

Note
  • If the current user does not have access rights to the printer settings, [User Prompt] and its setting will be grayed out and not available for changes.
