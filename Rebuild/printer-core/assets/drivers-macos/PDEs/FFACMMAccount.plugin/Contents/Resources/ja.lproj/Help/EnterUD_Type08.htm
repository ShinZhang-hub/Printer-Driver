［認証情報の入力］ダイアログボックス

［認証情報の設定］ダイアログボックスで、［ジョブごとに認証の入力画面を表示する］が選択されている場合に、このダイアログボックスが表示されます。
［使用する認証情報］で、ユーザーが入力できる認証情報を制限できます。

認証用IDを指定する

集計管理用のユーザーIDを指定する場合に選択します。お使いの機器側でジョブの認証管理をするときや、プリントジョブを集計するときに使用されます。選択すると、［User ID］、［パスワード］、［Account ID］の項目が表示されます。

補足
  • ［使用する認証情報］で、［User ID / Account ID］、または［すべて］を選択した場合に設定できます。

User ID（ジョブオーナー名）

User ID（ジョブオーナー名）を入力します。User IDの最大文字数は、32文字です。
User IDは、ジョブの認証管理をするときや、プリントジョブを集計するときに使用されます。
入力したUser IDは、ユーザーごとにプリンターアイコンに対して登録されます。

注記
  • User IDとパスワードは、間違って入力すると印刷されません。
  • User IDとパスワードは、お使いの機器の管理者に確認してください。
補足
  • ［IDを入力する］から［ログイン名を使用する］に変更し、問題が発生した場合は［標準に戻す］ボタンをクリックしてください。

パスワード

User ID（ジョブオーナー名）に対するパスワードを入力します。半角英数文字で4～12文字の範囲で入力します。
入力したパスワードは、ドット（・）で表示されます。
パスワード無しのUser IDの場合は、空欄にします。

注記
  • User IDとパスワードは、間違って入力すると印刷されません。
  • User IDとパスワードは、お使いの機器の管理者に確認してください。
 

Account ID

集計管理するためのAccount IDを入力します。半角英数文字で32文字まで入力できます。

注記
  • User IDとパスワードは、間違って入力すると印刷されません。
  • User IDとパスワードは、お使いの機器の管理者に確認してください。
補足
  • User ID、または蓄積用ユーザーIDは、必ず入力してください。

蓄積用IDを指定する

一般ユーザーが任意に課金管理の設定を変更できないように制限するために蓄積用ユーザーIDを登録します。お使いの機器のジョブ確認をすると、保存文書内の認証プリントのID名として表示されます。選択すると、［蓄積用ユーザーID］、［暗証番号］の項目が表示されます。
［使用する認証情報］で、ユーザーが入力できる認証情報を制限できます。

補足
  • User ID、または蓄積用ユーザーIDは、必ず入力してください。
  • ［使用する認証情報］で、［蓄積用ユーザーID］、または［すべて］を選択した場合に設定できます。

蓄積用ユーザーID

一般ユーザーが任意に課金管理の設定を変更できないように制限するために蓄積用ユーザーIDを登録します。お使いの機器のジョブ確認をすると、保存文書内の認証プリントのID名として表示されます。
蓄積用ユーザーIDの最大文字数は、24文字です。
お使いの機器側での操作方法については、機器のマニュアルを参照してください。

暗証番号

蓄積用ユーザーIDに対する暗証番号を入力します。半角数字で12文字以内で入力します。
入力した番号は、ドット（・）で表示されます。空欄のまま［OK］ボタンをクリックすると、暗証番号なしの設定になります。
