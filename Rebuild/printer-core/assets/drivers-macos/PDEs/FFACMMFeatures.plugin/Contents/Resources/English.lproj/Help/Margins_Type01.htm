[Binding Edge Erase] dialog box

Applies Binding Edge Erase at the center of the paper to avoid printing text at the fold that becomes lost or illegible.

Auto-Fit

Selecting this check box automatically reduces the image to fit onto the narrower print area caused by the application of Binding Edge Erase before printing.

Deselecting this check box shifts the image towards the opposite side of the Binding Edge Erase according to the width of the center Binding Edge Erase before printing. Note that this may shift the image outside the print area and clip it.

Margins

Specifies the width of the Binding Edge Erase.

You can specify any value in millimeters from 0 to 25 mm in units of 1 mm. For inches, you can specify any value from 0.0 to 1.0 inch in units of 0.1 inch. You can use the keyboard or the up and down arrows to specify a value.

The specified Binding Edge Erase is applied to the inside edge of the respective pages.

Units

Select the unit of measurement for [Margins].

[Millimeters] radio button

Select this radio button to change the unit of measurement for [Margins] to millimeters.

[Inches] radio button

Select this radio button to change the unit of measurement for [Margins] to inches.
