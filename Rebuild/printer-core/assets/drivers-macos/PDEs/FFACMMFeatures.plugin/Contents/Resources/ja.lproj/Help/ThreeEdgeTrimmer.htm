断裁

二つ折りされた用紙の背の反対側と上下を断裁します。背とは、用紙がとじられた辺になります。

仕上がりサイズ

断裁したあとの仕上がりサイズの［幅］、［高さ］、［仕上がり位置調整］を指定します。
仕上がりのサイズは、ミリ単位の場合は0.1 mm刻みに、インチ単位の場合は0.01 inch刻みに指定できます。キー入力、または▲▼ボタンで指定します。
仕上がりのサイズは、印刷する用紙によって異なります。

幅

仕上がりサイズの幅を指定します。

高さ

仕上がりサイズの高さを指定します。

仕上がり位置調整

仕上がり位置を指定します。

単位

単位表示を、ミリまたはインチに切り替えます。
