Offset Stacking

When the unit of pages or the unit of copies is selected, the output paper will be offset by the specified unit. It allows you to identify one set of printouts from another.
You can set up the unit of pages and the unit of copies in the following dialog box.

[Offset per Pages] dialog box

Specify the unit of pages. This dialog box appears when [Offset per Pages] is selected in [Offset Stacking].
Specify the number of pages from 2 to 65000 in units of 1. You can use the keyboard or the up and down arrows to specify a value.

Note
  • This function becomes available when [Pages per Sheet] is selected "1" at the [Layout] panel.

[Offset per Units] dialog box

Specify the unit of copies. This dialog box appears when [Offset per Units] is selected in [Offset Stacking].
Specify the number of copies from 2 to 9999 in units of 1. You can use the keyboard or the up and down arrows to specify a value.

Note
  • [Offset per Units] is not available when [Collated] is selected.
