Print Type Always with Hard Disk

Select Job Type

Select one of the following job types: "Normal Print", "Secure Print", "Sample Print", or "Delayed Print".
"Normal Print" is always available for selection but "Secure Print", "Sample Print" and "Delayed Print" are only available when "Hard Disk" is set to "Available" in the Printer Info.

"Secure Print"

"Secure Print" stores print data temporarily on the printer to be printed at a convenient time when the user is by the printer. You can specify this feature to print confidential documents. A user ID is required in the "User ID" field to process a Secure Print job.
Please refer to the printer manual on how to output the document at the printer.

Note
When no password is entered, the Secure Print job can be released without going through password authentication at the printer.

"Sample Print"

If you are printing multiple copies in one print job, "Sample Print" allows you to print only the first copy for checking before proceeding with the remaining copies. A user ID is required in the "User ID" field to process the Sample Print job.

Note
This feature will not be available if you are printing one copy or if you have not set the job to be collated.

"Delayed Print"

Delayed Print enables you to store print data temporarily in the printer to be output at a specified time.

User ID

Enter a user ID for Secure Print and Sample Print jobs.
The user ID should not exceed 24 characters.
You cannot use the following characters:
\ ' ,

Password

Enter the password for the "User ID" for Secure Print.
The password should not exceed 12 numbers. The numbers entered will be displayed as bullet.

Note
When no password is entered, you can retrieve and print a Secure Print job without any password validation at the printer.

Retrieve Document Name

Select the method to specify the document name for Secure Print, Sample Print, and Delayed Print.
If you have selected "Auto Retrieve", the document name set in the application will be used as the document name. If this document name is longer than 24 characters, only the first 24 characters will be displayed. No user input is allowed.
If you have selected "Enter Document Name", enter a name for the document in the "Document Name".

Document Name

This item is used when "Enter Document Name" is selected in "Retrieve Document Name".
Enter a document name not exceeding 24 characters.
You cannot use the following characters:
\ ' ,

Delayed Print

When Delayed Print is selected, enter the time for printing to begin.
You can specify any time from 12:00(AM) to 11:59(PM).
