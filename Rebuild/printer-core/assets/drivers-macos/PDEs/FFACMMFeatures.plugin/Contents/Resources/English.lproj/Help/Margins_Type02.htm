[Binding Edge Erase] dialog box

Adding a Binding Edge Erase at the center of the paper to avoid text printed at the fold being lost or illegible.

Margins

Specifies the width of the Binding Edge Erase.

You can specify any value in millimeters from 0 to 25 mm in units of 1 mm. For inches, you can specify any value from 0.0 to 1.0 inches in units of 0.1 inch. You can use the keyboard or the up and down arrows to specify a value.

The specified Binding Edge Erase is added to the inside edge of the respective pages.

Units

Select the unit of measurement for [Margins].

[Millimeters] radio button

Select this radio button to change the unit of measurement for [Margins] to millimeters.

[Inches] radio button

Select this radio button to change the unit of measurement for [Margins] to inches.
