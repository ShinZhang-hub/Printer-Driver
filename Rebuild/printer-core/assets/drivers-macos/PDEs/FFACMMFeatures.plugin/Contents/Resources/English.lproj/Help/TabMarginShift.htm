Tab Margin Shift

Specify this feature to shift and print the image such that a margin will be left for printing of the tabbed area on the Tab Stock.

Shift

To use the "Tab Margin Shift" feature, specify the width of the tabbed area on the Tab Stock. You can specify the width by entering a value from 0.0 to 15.0mm in units of 0.1mm or 0.00 to 0.59 inch in units of 0.01 inch, using the keyboard or the scroll button.

Units

Select the unit of measurement for [Shift].

[Millimeters] radio button

Select this radio button to change the unit of measurement for margin shift to millimeters.

[Inches] radio button

Select this radio button to change the unit of measurement for margin shift to inches.
